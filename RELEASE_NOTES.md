Local fabrication exporter for KiCad 10.0 (validated on 10.0.6 macOS):

- Multi-layer Gerber and Excellon ZIP, grouped BOM and both-side mm CPL.
- MPN/Manufacturer aliases normalized per component; different manufacturers remain separate.
- Basic report for missing fields, missing Edge.Cuts objects and BOM/placement differences.
- No upload or commercial-service connection; GPL-3.0-or-later.

This is a testing release using KiCad's legacy SWIG runtime. KiCad 8/9 and Windows/Linux have not been validated. Review the pre-flight report and fabrication files before use.
